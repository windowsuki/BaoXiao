# 实现与范围

首页遵循确认的「统计卡片 → 录入按钮 → 支出列表」，详情页集中管理金额、状态、材料和到账。

Room 表：expenses、attachments、receipts；附件以 UUID 文件名保存在 files/attachments，原文件名存入数据库。分享时生成原字节副本，使用 FileProvider 临时读取权限。

云端仅打包源码。收到文件后先选择支出；选择新建时保留待导入文件，保存后再选择关联。完整备份包含回收站记录，恢复只导入尚不存在的支出，已有支出不覆盖。

0.1.2：录入页移除类别、项目、商家、报销单名称和备注，首页/详情/统计同步去掉对应展示。编辑使用原记录 copy，不清空旧字段；保留数据库结构及备份兼容性。移除相机入口，改用 PickMultipleVisualMedia(ImageOnly) 从图库多选，旧系统按 AndroidX 的支持自动回退到图片文档选择器。

0.1.3：学校报销一次全额到账，取消到账金额手填入口，申请金额按净支出计算。「全部到账」在 Room 事务内重读账目，以 max(0, paid - refunded - 已到账) 补一笔差额收款并标记 RECEIVED；重复操作不重复记账，旧部分到账与旧材料保留。编辑金额增加导致未收齐时退回已提交；金额不能改到低于已到账额，需先撤销错误到账记录。

「报账取消」写入既有 CANCELLED 状态，不删除记录、附件或到账历史。统一 ledgerTotals 过滤取消及回收站记录，供首页主额、待提交/已提交小计、累计支出、到账和月统计使用。恢复取消时，按历史已收款与净支出确定已到账或准备材料；回收站恢复保留原取消状态。CSV 保留原始金额，新增「计入统计」标志；完整备份格式与数据库 schema version 1 保持兼容。

升级包签名固定校验 0.1.2-final 证书，缺失或不符就阻止交付，临时构建只能用于测试。2026-10-25 原 Actions 签名缓存已不存在，尚未找到原私钥，所以目前不能生成可覆盖 0.1.2 的更新包。不要通过换 key 来绕过校验。

限制：PDF 由手机已有查看器打开；材料移除确认后删除应用副本；尚未支持独立自定义材料种类、跨支出共享附件、OCR和提醒。旧备份的 batch 等字段保留，不再提供同名报销单界面。
