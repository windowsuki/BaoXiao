# 报销账本 BaoXiao

Android 原生离线报销账本，Kotlin + Jetpack Compose + Room。

## 首版功能

- 首页：尚未收回垫款、待提交和已提交未到账金额；搜索与状态筛选。
- 支出：录入、编辑、日期、类别、项目、商家、备注、退款和报销单名称。
- 材料：多文件导入、拍照、图片缩略图、调用系统预览 PDF，按支付记录/账单/发票/补充材料分类。
- 分享：单个原文件分享；单笔或同名报销单打包 ZIP，包含 CSV 清单。
- 到账：支持分次到账、撤销错误到账记录；报销状态独立管理。
- 统计：按月份、类别和项目汇总实际支出。
- 回收站：恢复误删支出；材料仍保留。
- 完整备份与恢复：JSON 索引 + 原始附件 ZIP，恢复前检查文件哈希和路径，合并时不覆盖已有支出。
- 接收其他应用分享的文件，为既有支出添加材料。

金额以整数分保存，不使用浮点数计算。应用不申请联网权限，账目和附件不上传 GitHub。卸载应用会删除本地数据，请先从「更多 → 完整备份」导出。

材料缺项目前是提示，按本次报销要求判断，不会禁止提交。发票暂未支持跨支出共享；OCR、提醒和独立报销单管理页后续完善。

## 无需在电脑安装 Android Studio

将源码推送到 GitHub 的 main 分支，Actions 自动执行单元测试、Android Lint 和 APK 构建。在仓库 Actions 页面打开成功的 Build Android APK 运行，下载 BaoXiao-APK，解压后把 APK 传到手机安装。

也可在 Actions 页面手动 Run workflow。构建固定使用 JDK 17、Gradle 8.11.1、AGP 8.9.2 和 Android SDK 35。

**升级签名：**工作流将首次生成的调试签名缓存，以保持常规构建可覆盖安装。缓存仍可能被平台清理；长期使用请在仓库配置 `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD` 四个 Secrets，以便构建固定签名的 release APK。不要将签名私钥提交到公开仓库。签名改变后需要卸载重装，因此务必先备份。

## 真机验收

1. 录入 12.34 元支出，关闭并重新打开应用，确认数据保留。
2. 导入支付截图和 PDF 发票，检查分类、图片预览和 PDF 打开。
3. 转发 PDF 到微信/QQ，确认电脑端收到可打开的原文件。
4. 导入重复材料，确认提示跳过重复文件。
5. 记录两次到账，核对未收回余额；移入回收站后恢复。
6. 导出完整备份，在另一台设备恢复并核对账目和原文件。
7. 同名报销单打包，检查 ZIP 内材料和 CSV 金额清单。

编译通过不等同于真机验收通过，微信/QQ分享和拍照需在实际手机上验证。
