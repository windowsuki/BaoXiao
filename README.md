# 报销账本 BaoXiao

Android 原生离线报销账本，Kotlin + Jetpack Compose + Room。

## 首版功能

- 首页：尚未收回垫款、待提交和已提交未到账金额；搜索与状态筛选。
- 支出：录入、编辑名称、日期、支付金额和退款；报销金额自动按支付减退款计算。
- 材料：多文件导入、从图库多选图片、图片缩略图、调用系统预览 PDF，按支付记录/账单/发票/补充材料分类。
- 分享：单个原文件分享；单笔或全部支出打包 ZIP，包含 CSV 清单。
- 到账：点击「全部到账」自动补齐剩余金额并更新状态，无需输入数值；保留旧版分次到账记录，可撤销错误记录。
- 报账取消：记录和材料保留，排除累计支出、累计到账、垫款、首页小计和月份统计；可恢复报账。
- 统计：累计金额与按月份汇总实际支出，已取消和回收站记录不计入。导出清单增加「计入统计」列，保留历史金额便于核对。
- 回收站：恢复误删支出；材料仍保留。
- 完整备份与恢复：JSON 索引 + 原始附件 ZIP，恢复前检查文件哈希和路径，合并时不覆盖已有支出。
- 接收其他应用分享的文件，为既有支出添加材料。

金额以整数分保存，不使用浮点数计算。应用不申请联网权限，账目和附件不上传 GitHub。卸载应用会删除本地数据，请先从「更多 → 完整备份」导出。

材料缺项目前是提示，按本次报销要求判断，不会禁止提交。界面已移除类别、项目、商家、报销单名称和备注；旧记录的对应数据仍保留在数据库与完整备份中。发票暂未支持跨支出共享；暂不含 OCR 和提醒。

## 无需在电脑安装 Android Studio

将源码推送到 GitHub 的 main/master 或 codex/* 分支，Actions 自动执行 16 项单元测试、Debug/Release Lint 和 release 编译。云端只生成 BaoXiao-unsigned：未签名 APK、构建信息、校验和，以及官方 SDK 的 apksigner.jar。下载后在本机用永久签名文件签名；私钥和口令不上传 GitHub。

也可在 Actions 页面手动 Run workflow。构建固定使用 JDK 17、Gradle 8.11.1、AGP 8.9.2 和 Android SDK 35。

**升级签名：**用户已接受 0.1.2 到 0.1.3 的一次完整备份迁移。0.1.3 起改用永久本地 release 签名，公开证书指纹固定在 `config/release-signing.json`；包名仍为 `cn.baoxiao.ledger`、versionCode 为 4，Room 数据库和备份结构兼容。后续更新必须使用同一密钥并提高 versionCode。

原工作流仅把私钥存入 Actions 临时缓存。2026-10-25 排查时缓存已清空，没有原私钥备份，所以本次不能覆盖 0.1.2；迁移前务必使用旧版「完整备份」保存到应用外，并另复制一份到电脑。不要误选「导出全部材料与清单」，它不含恢复所需索引。确认备份保存后才换装新版，在新装空库中恢复，再检查账目和原文件。

本地私钥和口令在 Git 忽略的 `signing/` 中，另有源码目录外的私密备份 `C:/Users/wuyue/Documents/BaoXiao-signing-backup/`。签名脚本缺少密钥或发现指纹不符会直接停止，不能自动生成替代密钥。操作方式见 [固定签名与迁移](docs/SIGNING.md)。

## 真机验收

1. 录入 12.34 元支出，关闭并重新打开应用，确认数据保留。
2. 导入支付截图和 PDF 发票，检查分类、图片预览和 PDF 打开。
3. 转发 PDF 到微信/QQ，确认电脑端收到可打开的原文件。
4. 导入重复材料，确认提示跳过重复文件。
5. 点「全部到账」，核对金额自动补齐、状态变为已全部到账；重复点击不增加到账，旧部分到账只补差额。撤销错误到账后可重新全部到账。
6. 导出完整备份，在另一台设备恢复并核对账目和原文件。
7. 单笔或全部支出打包，检查 ZIP 内材料和 CSV 金额清单；检查图库多选、取消选择及重复图片导入。
8. 取消一笔报账，确认首页、累计金额和月份统计全部排除它，材料仍可查看；恢复后重新计入。回收站恢复不能自动恢复已取消的报账。
9. 本次先从 0.1.2 完整备份迁移到固定签名 0.1.3，确认原账目和附件恢复。之后用同一 release 证书的更高版本覆盖安装，确认数据保留。

编译通过不等同于真机验收通过，微信/QQ分享和图库选择需在实际手机上验证。
